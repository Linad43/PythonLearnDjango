# PythonLearnDjango

Учебный проект для изучения основ **Django** и создания простого веб-приложения на Python.

В проекте создано Django-приложение `catalog`, реализованы HTML-шаблоны и переход между страницами **Home** и
**Contacts**.

## 📁 Структура проекта

```text
PythonLearnDjango/
│
├── catalog/                 # Основное приложение проекта
│   ├── migrations/          # Миграции базы данных
│   │   └── __init__.py
│   │
│   ├── templates/           # HTML-шаблоны
│   │   ├── contacts.html    # Страница "Контакты"
│   │   └── home.html        # Главная страница
│   │
│   ├── __init__.py
│   ├── admin.py             # Настройки Django Admin
│   ├── apps.py              # Конфигурация приложения
│   ├── models.py            # Модели базы данных
│   ├── tests.py             # Тесты приложения
│   ├── urls.py              # URL-маршруты приложения
│   └── views.py             # Представления приложения
│
├── config/                  # Основная конфигурация Django
│   ├── __init__.py
│   ├── asgi.py              # Точка входа для ASGI
│   ├── settings.py          # Настройки проекта
│   ├── urls.py              # Основные URL-маршруты
│   └── wsgi.py              # Точка входа для WSGI
│
├── manage.py                # Управление Django-проектом
├── requirements.txt         # Зависимости проекта
└── README.md                # Документация проекта
```

## 🛠 Используемые технологии

* **Python**
* **Django**
* **HTML**
* **Git**

Зависимости проекта находятся в файле `requirements.txt`.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd PythonLearnDjango
```

### 2. Создание виртуального окружения

Linux/macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```powershell
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск Django-сервера

```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## 🌐 Страницы

В приложении `catalog` реализованы две основные страницы:

### Home

Главная страница проекта:

```text
/
```

Использует шаблон:

```text
catalog/templates/home.html
```

### Contacts

Страница с контактами:

```text
/contacts/
```

Использует шаблон:

```text
catalog/templates/contacts.html
```

Переход между страницами осуществляется с помощью URL-маршрутов Django.
